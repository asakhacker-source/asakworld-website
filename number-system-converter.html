Example and limitations

Decimal 45 is binary 101101, hexadecimal 2D and octal 55. The converter accepts non-negative integers only. It uses JavaScript BigInt internally, so it avoids ordinary floating-point precision loss; fractions, signed notation and prefixes such as 0x are intentionally not accepted.

Common mistakes

Do not use digits outside the selected base: 102 is not binary, and 2G is not hexadecimal. Keep leading zeroes only when their displayed representation matters.
