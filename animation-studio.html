How it works

Add an object, select it, and set keyframes at different points in time. The Studio linearly interpolates position, rotation, scale and opacity between those keyframes. Save projects as local JSON; images are embedded only in the saved project data. WebM export depends on your browser’s native MediaRecorder support. GIF export deferred.
